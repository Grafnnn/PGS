# Technical Documentation Assistant v1

## Назначение

Модуль находится во вкладке `Ресурсы → Техпомощник`. Основная база знаний проекта — общая папка Google Drive: пользователь задаёт вопрос, PGS находит подтверждающие фрагменты в документации этой папки и только затем формирует ответ. Каждый ответ показывает исходный файл Google Drive и страницу, лист или диапазон строк. Если подтверждения нет, модуль предлагает уточнить запрос или оформить RFI.

## Источники

- общая папка Google Drive в режиме read-only — основной источник;
- документы PGS без привязки к суточному рапорту — дополнительный источник;
- PDF с текстовым слоем, DOCX, XLS/XLSX, CSV и TXT;
- сканы без OCR и устаревший DOC отмечаются как недоступные для текстового поиска.

Без Google Drive поиск может работать по документам из storage PGS, но интерфейс явно обозначает этот режим как резервный и не выдаёт его за основную проектную базу.

## Скорость и стоимость

1. При подключении папки первая синхронизация запускается сразу.
2. Перед вопросом PGS проверяет свежесть индекса не чаще одного раза в 15 минут; Google Drive отдаёт метаданные, а содержимое скачивается только для новых или изменённых файлов.
3. До трёх изменённых файлов обрабатываются параллельно, чтобы ускорить большую первую синхронизацию без агрессивной нагрузки на Drive и PostgreSQL.
4. Неподдерживаемые типы определяются по имени/MIME до скачивания, поэтому изображения и архивы не расходуют лишний трафик.
5. Фрагменты и нормализованные термины сохраняются в PostgreSQL; GIN-индекс выбирает кандидатов без vector database и embeddings. При равной релевантности Google Drive имеет приоритет над дополнительными документами PGS.
6. В `gpt-4o-mini` отправляются не файлы целиком, а не более шести релевантных фрагментов.
7. Повторный идентичный вопрос возвращается из кэша до следующей версии индекса. Если локальный поиск не нашёл evidence, OpenAI не вызывается.
8. При отключённом OpenAI модуль остаётся полезным: показывает релевантные фрагменты и точные ссылки без внешнего запроса.

## Google Drive

Минимальная production-конфигурация:

```text
GOOGLE_DRIVE_CONNECTOR_MODE=read_only
GOOGLE_DRIVE_SERVICE_ACCOUNT_EMAIL=...
GOOGLE_DRIVE_SERVICE_ACCOUNT_PRIVATE_KEY=...
```

Папку проекта нужно предоставить указанному service account только на чтение. После этого пользователь вставляет ссылку в `Ресурсы → Техпомощник` и нажимает `Подключить и синхронизировать`. Для публичной общей папки вместо service account можно задать `GOOGLE_DRIVE_API_KEY`. Сервис использует только Google Drive API `drive.readonly`, поддерживает вложенные папки и ярлыки и не изменяет и не удаляет внешние файлы.

Последующие вопросы автоматически используют актуальный индекс. Если Google Drive временно недоступен, PGS явно предупреждает пользователя и может ответить только по последней успешно проиндексированной версии, не скрывая её состояние.

## Безопасность

- просмотр и вопросы требуют project `view` permission;
- настройка источника и перестроение индекса требуют project `edit` permission;
- права проверяются до чтения request body;
- AI-вызов выполняется только по кнопке и ограничен rate limit;
- OpenAI Responses API вызывается с `store: false`;
- ответы журналируются в `AiRun`, а secret-like значения редактируются;
- документы разных проектов никогда не участвуют в одном поиске.
