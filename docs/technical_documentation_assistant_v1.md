# Technical Documentation Assistant v1

## Назначение

Модуль находится во вкладке `Ресурсы → Техпомощник` и отвечает на технические вопросы только по документации выбранного проекта. Каждый ответ показывает документ и страницу, лист или диапазон строк. Если подтверждения нет, модуль предлагает уточнить запрос или оформить RFI.

## Источники

- документы PGS без привязки к суточному рапорту;
- общая папка Google Drive в режиме read-only;
- PDF с текстовым слоем, DOCX, XLS/XLSX, CSV и TXT;
- сканы без OCR и устаревший DOC отмечаются как недоступные для текстового поиска.

Google Drive не обязателен. Документы из storage PGS индексируются независимо от внешнего коннектора.

## Скорость и стоимость

1. Текст извлекается один раз для каждой версии документа.
2. Фрагменты и нормализованные термины сохраняются в PostgreSQL; GIN-индекс выбирает кандидатов без vector database и embeddings.
3. В `gpt-4o-mini` отправляются не файлы целиком, а не более шести релевантных фрагментов.
4. Повторный идентичный вопрос возвращается из кэша до следующей версии индекса.
5. Если локальный поиск не нашёл evidence, OpenAI не вызывается.
6. При отключённом OpenAI модуль остаётся полезным: показывает релевантные фрагменты и точные ссылки без внешнего запроса.

## Google Drive

Минимальная production-конфигурация:

```text
GOOGLE_DRIVE_CONNECTOR_MODE=read_only
GOOGLE_DRIVE_SERVICE_ACCOUNT_EMAIL=...
GOOGLE_DRIVE_SERVICE_ACCOUNT_PRIVATE_KEY=...
```

Папку проекта нужно предоставить указанному service account только на чтение. Для публичной общей папки вместо service account можно задать `GOOGLE_DRIVE_API_KEY`. Сервис использует только Google Drive API `drive.readonly`, не изменяет и не удаляет внешние файлы.

## Безопасность

- просмотр и вопросы требуют project `view` permission;
- настройка источника и перестроение индекса требуют project `edit` permission;
- права проверяются до чтения request body;
- AI-вызов выполняется только по кнопке и ограничен rate limit;
- OpenAI Responses API вызывается с `store: false`;
- ответы журналируются в `AiRun`, а secret-like значения редактируются;
- документы разных проектов никогда не участвуют в одном поиске.
